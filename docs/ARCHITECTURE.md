# دليل الباك

إعادة تنظيم طبقية عملية؛ لا تغييرات في الجداول أو عناوين الـAPI أو متغيرات البيئة أو أوامر التشغيل والاستيراد.

| الطبقة | مسؤوليتها |
| --- | --- |
| `app/routers/` | HTTP، معاملات الطلب، التحقق من الصلاحيات، استدعاء الخدمة |
| `app/schemas/` | عقود الطلب والاستجابة |
| `app/services/` | عمليات الحساب والملف الشخصي ودليل التعليم والمساعد |
| `app/repositories/` | استعلامات SQLAlchemy وإجراءات التخزين للمستخدمين ودليل التعليم |
| `app/domain/` | قواعد التطبيع والتمثيل والأخطاء المستقلة عن FastAPI |
| `app/infrastructure/` | البريد وMinIO واتصال مزود الذكاء الاصطناعي |
| `app/models/` | نماذج ORM الحالية، دون تغيير أسماء الجداول أو أعمدتها |
| `app/core/` | الإعدادات والأمان وتوصيل قاعدة البيانات |
| `app/main.py` | تجميع التطبيق ومعالج أخطاء الخدمات |
| `scripts/` و`tools/` | أوامر الاستيراد والتحضير الحالية |

الخدمة ترفع `ApplicationError`، و`main.py` يحولها لنفس HTTP status و`detail` السابقين. أخطاء FastAPI الخاصة بمعاملات الطلب والمصادقة تبقى في طبقة HTTP.

`services/email.py` و`services/minio_storage.py` جسور استيراد للتوافق فقط؛ التعديل الفعلي في `infrastructure/`. `services/education.py` يحافظ على استيرادات أدوات التحضير القديمة حتى لا تتعطل scripts.

هذه بنية طبقية نحو Clean Architecture، وليست ادعاءً باستقلال كامل عن ORM: خدمات الحساب والملف الشخصي ما زالت تتعامل مع نموذج المستخدم وSession للحفاظ على حدود العمليات الحالية. تحويلها إلى كيانات مستقلة وواجهات Repository محقونة لاحقًا يحتاج مرحلة مخصصة واختبارات إضافية.

## التحقق

`python -m unittest discover -s tests`

الاختبارات الجديدة في `test_layers.py` تستخدم SQLite معزولة وتستبدل البريد/التخزين بمضاعفات اختبار؛ لا ترسل رسائل ولا تعدل قاعدة الإنتاج. التشغيل يبقى `uvicorn app.main:app --reload`. لا حاجة لإعادة استيراد المدارس أو تعديل الداتابيز لهذا التنظيم.
